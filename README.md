🚀 QUICK START
01 — Clone
git clone https://github.com/developersairaj/Sentinelx-Cybersecurity-Platform.git

cd Sentinelx-Cybersecurity-Platform
02 — Configure
cp .env.example .env

Edit .env and configure your development secrets.

03 — Launch
docker compose up --build
⚡ Open SentinelX
Service	Address
🛡️ Command Center	http://localhost:3000
⚡ Backend API	http://localhost:8000/api/v1
📚 API Docs	http://localhost:8000/api/v1/docs
🐘 PostgreSQL	localhost:5432
⚡ Redis	localhost:6379
💻 WITHOUT DOCKER
Backend
cd backend

python -m venv .venv
Windows
.venv\Scripts\Activate.ps1
Linux / macOS
source .venv/bin/activate

Install dependencies:

pip install -r requirements/dev.txt

Start API:

uvicorn app.main:app --reload
Frontend
cd frontend

npm install

npm run dev

🔐 SECURITY BY DESIGN

SentinelX follows a simple defensive principle:

┌─────────────────────────────────────────┐
│                                         │
│       AUTHORIZATION BEFORE ACTION       │
│                                         │
│       VISIBILITY BEFORE RESPONSE        │
│                                         │
│       INTELLIGENCE BEFORE PRIORITY      │
│                                         │
│       AUDITABILITY THROUGHOUT            │
│                                         │
└─────────────────────────────────────────┘

Network scanning is designed for explicitly authorized targets only.

The platform does not implement:

❌ Exploitation
❌ Credential harvesting
❌ Persistence
❌ Evasion tooling
❌ Unauthorized access

The platform focuses on:

✅ Defensive security
✅ Asset visibility
✅ Vulnerability management
✅ Authorized assessment
✅ Risk prioritization
✅ Threat intelligence
✅ Security analytics
✅ Governance
✅ Auditability
